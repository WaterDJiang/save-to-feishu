Save to Feishu 使用帮助

在浏览器侧栏中整理网页，保存到飞书、Markdown，并支持 Notion 与飞书同步

📖 快速开始

1让插件连接飞书

  1. 访问 飞书开放平台
  2. 登录后点击"创建企业自建应用"
  3. 填写应用名称（如"Save to Feishu"），选择应用类型
  4. 创建完成后，在"凭证与基础信息"中复制飞书给插件的两串钥匙：
    • App ID（第 1 串钥匙）
    • App Secret（第 2 串钥匙）

2允许插件保存到表格

  1. 在应用后台，点击"权限管理"
  2. 添加以下权限：
    • 读写多维表格：用于把网页内容保存进去
    • 查看多维表格结构：用于读取表格里有哪些列
  3. 点击"申请权限"并等待审批（通常自动通过）

3准备一个飞书资料库

  1. 在飞书中创建一个新的多维表格
  2. 添加需要的列，例如：
    • 标题（文本）
    • 链接（文本/链接）
    • 正文（文本）
    • 图片（附件）
    • 保存时间（日期）
  3. 点击表格右上角的"分享"按钮
  4. 开启"分享到互联网"或分享给应用
  5. 复制表格链接，之后直接粘贴到插件里即可

4在插件里添加资料库

  1. 点击扩展图标，选择"设置"
  2. 填入飞书给插件的两串钥匙（App ID 和 App Secret）
  3. 点击"添加资料库"，给资料库起个名字
  4. 粘贴完整的飞书表格链接
  5. 点击"读取表格列名"，告诉插件标题、链接、备注等内容分别放到哪一列
  6. 保存

5开始使用

  1. 打开想要保存的网页
  2. 点击浏览器工具栏里的扩展图标，打开剪藏侧栏
  3. 确认摘要、标签、资料类型和目标资料库
  4. 点击"保存到飞书"，也可以单独下载 Markdown

✨ 浏览器本地整理建议

1自动生成保存前建议

  1. 打开网页后点击扩展图标
  2. 侧栏会读取当前网页标题、链接、正文和选中文本
  3. 如果当前 Chrome 支持内置 AI，插件会自动生成摘要、标签和资料类型
  4. 这些内容只是建议，你可以修改后再保存
说明：不需要额外 API key

第一版 AI 整理使用 Chrome 浏览器本地能力，不需要填写 OpenAI、豆包或 Claude 的 API key，也不会把网页正文发送到插件开发者服务器。当前 Chrome 暂不支持时，侧栏会提示可以手动填写，保存流程不受影响。

🔄 Notion 与飞书同步

1在 Notion 创建一个连接

  1. 在插件设置页点击"打开 Notion 获取连接码"，或访问 Notion Integrations
  2. 创建一个内部连接，复制 Notion 生成的 连接码（通常以 secret_ 开头）
  3. 打开要同步的 Notion 数据库页面，点击右上角"···" → "Connections"
  4. 将刚创建的连接添加到该数据库

2保存 Notion 连接码

  1. 进入扩展设置页，选择"Notion 与飞书同步"
  2. 粘贴 Notion 连接码
  3. 点击"检查连接"
  4. 连接成功后，扩展会列出它能看到的 Notion 数据库

3创建一条同步规则

  1. 填写规则名称，例如"Notion 选题库同步到飞书"
  2. 选择同步方向：Notion → 飞书 或 飞书 → Notion
  3. 选择或粘贴 Notion 数据库页面链接
  4. 从已经连接的飞书资料库中选择目标表格
  5. 设置这次最多同步多少条，首次建议先用 10-20 条测试

4告诉插件每一列怎么对应

  1. 点击"读取两边列名"，让插件读取 Notion 和飞书各有哪些列
  2. 如果两边列名相同，可以点击"自动匹配同名列"
  3. 检查每一行：左边是要同步的列，右边是同步后放入哪一列
  4. 点击"保存规则"，以后可以复用这组设置
  5. 点击"开始同步"，扩展会按当前方向同步资料
💡 提示：从侧栏快速进入

在剪藏侧栏中点击"Notion 与飞书同步"，可以直接打开同步规则设置页。

⚠️ 注意：同步范围

当前需要手动点击"开始同步"，插件不会自动监听 Notion 或飞书的变化。建议优先使用文本、数字、日期、单选、多选、网址、邮箱、复选框这些普通列；人员、附件等复杂列可能会跳过或变成文字。

💡 使用技巧

💡 提示：表格排序

在表格列表页面，可以使用上下箭头调整表格顺序，让常用的表格排在前面。

💡 提示：列类型

建议：标题用"文本"，链接用"链接"或"文本"，正文用"多行文本"，资料类型用"单选"或"文本"，图片用"文本"保存图片网址。

💡 提示：批量保存

虽然扩展不支持批量保存多个网页，但您可以快速连续保存多个页面，所有内容都会按顺序添加到表格中。

💡 提示：Notion 与飞书同步

如果你同时使用 Notion 和飞书，可以为不同资料库建立多个同步规则，例如"Notion 选题库 → 飞书团队表"或"飞书研究资料 → Notion 个人库"。

⚠️ 常见问题

Q: 保存失败，提示没有权限？

请检查：

  • 飞书应用是否已经允许读写表格
  • 表格是否已允许这个应用编辑
  • App ID 和 App Secret 是否复制完整
Q: 保存失败，提示找不到某一列？

列名不匹配。请重新点击"读取表格列名"，再确认每一列应该保存什么。

Q: 链接没有保存成功？

链接列类型不合适。请在飞书表格中，将对应列改成"超链接"或"文本"。

Q: 提取的内容不完整？

某些网页使用动态加载或特殊结构，可能导致内容提取不完整。尝试刷新页面后再次保存。

Q: 为什么没有自动生成摘要和标签？

这取决于当前 Chrome 是否支持内置 AI，以及本地模型是否已经准备好。没有自动生成时，可以直接手动填写摘要和标签，不会影响保存。

Q: Notion 能连接，但看不到我的数据库？

通常是因为你还没有把 Notion 连接添加到目标数据库。请打开 Notion 数据库页面，点击右上角"···" → "Connections"，添加你创建的连接，然后回到扩展重新读取列名。

Q: 同步后有些列是空的？

请检查两边的列类型是否兼容。建议优先对应文本、数字、日期、单选、多选、网址、邮箱、复选框这些普通列。人员、附件等复杂列可以先改成文本列保存。

Q: 如何删除已保存的配置？

在扩展设置页面，点击表格卡片上的"删除"按钮即可删除该表格配置。如需清除所有数据，可以卸载扩展后重新安装。

🔒 隐私与安全

⚠️ 安全提醒
  • 你的 App ID 和 App Secret 仅存储在本地浏览器中
  • Notion 连接码同样仅存储在本地浏览器中，导出设置时默认不会包含
  • AI 整理只在浏览器本地能力可用时运行，不需要额外 API key
  • 所有数据直接发送到您的飞书表格，不经过第三方服务器
  • 建议不要将连接密钥分享给他人
  • 定期检查飞书应用权限设置
