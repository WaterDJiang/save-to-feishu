# Chrome Web Store 商品列表文案

## 基本信息

### 商品名称
**Save to Feishu - 网页知识剪藏到飞书**

### 简短描述（最多 132 字符）
一键剪藏网页，自动整理成飞书资料库和 Markdown 笔记。

### 详细描述

```
Save to Feishu 是一款网页知识整理工具，帮助您把文章、资料、选题和研究素材一键剪藏成飞书资料库与 Markdown 笔记。

🚀 核心功能

• 零配置 Markdown：不配置飞书也能先保存结构化 Markdown 笔记
• 一键剪藏：自动提取网页标题、正文、摘要、图片、链接和选中文本
• 飞书资料库：保存到多维表格和飞书文档，形成可筛选的知识库
• 知识库模板：内置阅读收件箱、研究资料库、内容选题库
• 整理闭环：保存前补充标签、状态、个人备注和下次回顾时间
• 双出口保存：可选择飞书优先、Markdown 优先或两者同时保存
• Notion 与飞书同步：在 Notion 数据库和飞书表格之间同步资料

📋 适用场景

• 行业研究：沉淀报告、资讯、竞品页面和资料来源
• 内容创作：收集选题、金句、观点和素材摘录
• 个人阅读库：把待读文章先放入“未处理”收件箱
• 团队资料库：用飞书多维表格统一管理网页资料
• Markdown 笔记：同步到 Obsidian、Logseq、Notion 或 Git 仓库

🔒 隐私安全

• 所有数据仅存储在您的飞书表格中
• 不收集任何用户行为数据
• 仅在您主动保存或同步时访问飞书、Notion

🛠 配置简单

1. 先直接保存 Markdown，零配置验证剪藏效果
2. 复制飞书给插件的两串钥匙（App ID 和 App Secret）
3. 创建飞书表格，并允许插件编辑
4. 粘贴表格链接，选择资料库模板
5. 开始剪藏、标记和整理网页知识

💡 使用提示

• 首次使用需要先连接飞书
• 表格需要开启"允许应用编辑"权限
• 建议用文本、链接、日期等普通列保存资料

---

如有问题或建议，欢迎反馈！
```
