# 0.5.6 审核版本发布计划

更新时间：2026-06-15

## 目标

将插件全局版本统一更新为 `0.5.6`，构建并生成可提交 Chrome Web Store 审核的发布压缩包。

## 发布范围

1. 统一版本号：
   - Chrome 扩展清单；
   - npm 包元数据和锁文件；
   - 本地配置版本与兼容修复默认值；
   - 设置页、侧栏更新卡等用户可见版本文案；
   - 使用当前版本的测试数据与断言。
2. 更新 `0.5.6` 用户可见更新说明，体现本次回顾工作流优化。
3. 执行生产构建。
4. 从 `dist` 根目录生成 Chrome Web Store 审核压缩包。

## 数据和隐私边界

- 不修改权限、host permissions 或远程服务范围。
- 发布包不包含源码、配置密钥、日志、测试文件或历史发布包。
- 只打包生产构建输出中的扩展运行文件。

## 打包规则

- 输出目录：`release/`
- 文件名：`save-to-feishu-0.5.6-google-review-YYYYMMDD-HHMMSS.zip`
- 压缩包根目录必须直接包含 `manifest.json`，不能额外嵌套 `dist/`。

## 验收标准

- 当前版本相关位置全部为 `0.5.6`。
- `npm run build` 成功。
- `dist/manifest.json` 版本为 `0.5.6`。
- 审核包内 `manifest.json` 版本为 `0.5.6`。
- 审核包不包含 `.env`、源码、测试和其他压缩包。
- `git diff --check` 通过。
