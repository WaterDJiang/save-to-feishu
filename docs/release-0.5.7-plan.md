# 0.5.7 版本同步计划

更新时间：2026-06-20

## 目标

将当前开发版本统一升级为 `0.5.7`，并使清单、本地配置兼容、用户可见版本文案和当前版本测试数据保持一致。

## 范围

1. 更新 `package.json`、`package-lock.json` 和 Chrome 扩展清单。
2. 更新本地配置默认版本与配置修复默认值。
3. 更新设置页和侧栏的当前版本更新说明，内容对应首次保存的飞书/Markdown 双入口。
4. 更新当前版本相关测试数据与断言。
5. 保留 `0.5.6` 的历史发布计划、日志和旧版本升级来源，不改写历史事实。
6. 基于已验证的 `dist/` 生成可直接上传 Chrome Web Store 的审核 ZIP；压缩包根目录必须直接包含 `manifest.json`。

## 数据与发布边界

- 不修改权限、host permissions、网络服务或用户数据。
- 已按用户后续明确请求执行一次生产构建；不生成审核包。
- 不覆盖当前工作区中其他未提交功能改动。
- 审核包只包含 `dist/` 的运行时文件，不包含源码、测试、文档、本地配置或历史发布包。

## 验收标准

- 活跃源码中的当前版本号统一为 `0.5.7`。
- 旧版本号只保留在历史发布文档或作为 `previousVersion: '0.5.6'` 的升级来源。
- `git diff --check` 通过。
- `npm run build` 成功，且 `dist/manifest.json` 为 `0.5.7`。
- 审核 ZIP 根目录包含 `manifest.json`，其版本为 `0.5.7`；包内包含 manifest 声明的后台、侧栏、设置页、内容脚本、图标和静态资源。
- ZIP 完整性检查通过，且不包含源码、测试、文档或敏感本地配置。
