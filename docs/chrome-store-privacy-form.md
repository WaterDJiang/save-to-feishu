# Chrome Web Store 隐私权表单填写指南

## 单一用途说明

```
Save to Feishu 是一款浏览器扩展，帮助用户在 Chrome 侧栏中整理网页内容，并保存到飞书多维表格、飞书文档或 Markdown。扩展仅在用户主动点击保存或同步时提取当前网页的标题、URL、正文内容和图片，并按照用户配置的字段映射关系保存到指定位置。
```

---

## 权限说明

### storage 权限

```
用于在浏览器本地存储用户的飞书应用凭证（App ID、App Secret）和表格配置信息（表格ID、字段映射关系）。所有数据仅保存在用户本地，不会上传到任何服务器。
```

### activeTab 权限

```
用于获取当前活动标签页的网页信息，包括页面标题、URL 和正文内容。仅在用户点击扩展图标时触发，不会持续监控用户浏览行为。
```

### scripting 权限

```
用于在网页中执行内容提取脚本，获取网页正文和图片链接。仅在用户主动保存网页时执行，不会自动运行或收集无关数据。
```

### tabs 权限

```
用于管理浏览器标签页，确保在正确的标签页中执行保存操作。仅在用户主动触发保存功能时使用，不会监控或记录用户的浏览历史。
```

### contextMenus 权限

```
用于在右键菜单中提供“保存到飞书”的快捷入口，仅在用户主动点击时触发。
```

### sidePanel 权限

```
用于在浏览器原生侧栏中展示网页剪藏工作台。用户点击扩展图标后打开侧栏，在侧栏中预览、整理并保存当前网页。
```

### 主机权限 (<all_urls>, https://open.feishu.cn/*, https://*.feishu.cn/*, https://api.notion.com/*, https://*.qpic.cn/*, https://*.qlogo.cn/*)

```
用于在用户主动打开侧栏或右键保存时读取当前网页内容，并与飞书开放平台 API、Notion API 通信。公众号图片资源（qpic/qlogo）用于完成图片链接保存。所有数据直接发送到用户配置的飞书或 Notion 服务，不经过扩展开发者的服务器。
```

---

## 远程代码使用

**选择：不，我并未使用远程代码**

理由：
```
本扩展的所有代码都包含在扩展程序包中，没有引用任何外部 JavaScript 文件或使用 eval() 执行远程代码。扩展仅通过 HTTPS 与飞书官方 API 通信，这是正常的 API 调用而非远程代码执行。
```

---

## 数据使用

### 收集的用户数据

**勾选：网站内容**

说明：
```
本扩展仅在用户主动保存网页时，收集当前网页的以下内容：
- 网页标题
- 网页 URL
- 网页正文文本
- 网页主图链接
- 用户手动填写的标签、资料类型、备注

这些数据仅用于保存到用户指定的飞书表格，不会用于其他目的。
```

### AI 数据处理说明

```
本扩展不接入 OpenAI、豆包、Claude 等云端 AI API，也不要求用户填写云端 API key。整理建议仅在 Chrome 内置 AI 可用时由浏览器本地能力生成；不可用时用户仍可手动填写并保存。
```

### 不收集的数据

以下选项**不勾选**：
- 个人身份信息
- 健康信息
- 财务和付款信息
- 身份验证信息
- 个人通讯
- 位置
- 网络记录
- 用户活动
