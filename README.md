## 功能特性

- **零配置 Markdown**：不配置飞书也能直接把网页保存为结构化 Markdown 笔记
- **浏览器侧栏剪藏**：点击插件图标打开正式侧栏，预览网页后再保存
- **一键提取**：自动提取网页标题、正文、摘要、图片、链接和选中文本
- **高质量摘录**：选中网页片段后右键保存为观点、案例、数据、金句或问题
- **AI 信息整理建议**：默认使用 Chrome 内置 AI，也可填写自己的 API Key 调用自有 AI 服务
- **飞书资料库**：保存到多维表格和飞书文档，形成可筛选、可协作的知识库
- **整理信息**：保存前补充标签、状态、个人备注和下次回顾时间
- **资料库模板**：内置阅读收件箱、研究资料库、内容选题库三套常用模板
- **最近保存与待回顾**：在侧栏查看最近剪藏，并集中打开已到回顾日期的资料
- **可分享模板**：复制不含凭证和资料库标识的模板代码，与团队复用字段结构
- **一键问题反馈**：从侧栏或设置页打开预填环境信息的反馈页面
- **两种保存方式**：可只保存到飞书、只保存到电脑，或两边都保存
- **Notion 与飞书同步**：在 Notion 数据库和飞书表格之间同步资料
- **克制的评分邀请**：仅在成功保存达到里程碑后提示，可延后且不做远程追踪
- **克制清爽 UI**：采用原生侧栏形态，适合长期作为网页知识剪藏工作台

## 适用场景

- **行业研究**：把报告、新闻、竞品页面剪藏到飞书资料库，按来源、标签、状态追踪
- **内容创作**：收集选题、金句和素材，保存个人备注，后续进入创作流程
- **个人阅读库**：先进入“未处理”收件箱，再精读、整理、回顾，Markdown 可同步到 Obsidian/Logseq/Git

## 3 分钟搭建网页知识库

1. 先安装扩展，直接点击“保存 Markdown 笔记”验证剪藏质量
2. 在飞书创建一个多维表格，按“阅读收件箱”“研究资料库”或“内容选题库”准备好列名
3. 在设置页粘贴飞书表格链接，读取列名后选择资料库模板
4. 在“默认保存方式”选择“只保存到飞书”“只保存到电脑”或“两边都保存”
5. 点击插件图标打开剪藏侧栏，确认摘要、标签、资料类型和备注后保存

## 安装

### 从 Chrome Web Store 安装（推荐）

1. 访问 Chrome Web Store 页面（即将上线）
2. 点击"添加至 Chrome"
3. 在弹出的对话框中点击"添加扩展程序"

### 手动安装（开发者模式）

1. 下载本项目的最新 Release 或克隆仓库
2. 运行 `npm install` 安装依赖
3. 运行 `npm run build` 构建项目
4. 打开 Chrome 浏览器，进入 `chrome://extensions/`
5. 开启右上角的"开发者模式"
6. 点击"加载已解压的扩展程序"
7. 选择项目中的 `dist` 文件夹

## 快速开始

### 1. 让插件连接飞书

1. 访问 [飞书开放平台](https://open.feishu.cn/app)
2. 登录后点击"创建企业自建应用"
3. 填写应用名称，选择应用类型
4. 在"凭证与基础信息"中复制 **App ID** 和 **App Secret**，这是飞书给插件的两串钥匙
5. 在"权限管理"中添加读写多维表格的权限

### 2. 创建多维表格

1. 在飞书中创建一个新的多维表格
2. 添加需要的列，例如：
   - 标题（文本）
   - 链接（文本/链接）
   - 正文（多行文本）
   - 图片（附件）
   - 保存时间（日期）
3. 点击表格右上角的"分享"按钮
4. 开启"允许应用编辑"权限
5. 复制完整的表格链接

### 3. 配置扩展

1. 点击扩展图标打开侧栏，再点击"打开设置"
2. 填入 App ID 和 App Secret
3. 点击"添加资料库"，给它起个名字
4. 粘贴完整的飞书表格链接
5. 读取列名，告诉插件标题、链接、备注分别放到哪一列
6. 保存

### 4. 开始使用

1. 打开想要保存的网页
2. 点击扩展图标打开剪藏侧栏
3. 确认摘要、标签、资料类型和目标资料库
4. 点击"保存到飞书"，也可以下载 Markdown

## 开发

### 技术栈

- **框架**：React 18 + TypeScript
- **构建工具**：Vite 6
- **样式**：CSS Modules + 自定义 CSS
- **图标**：Lucide React
- **API**：飞书开放平台 API

### 项目结构

```
save-to-feishu/
├── public/                  # 静态资源
│   ├── icons/              # 扩展图标
│   └── manifest.json       # 扩展清单
├── src/
│   ├── background/         # Service Worker
│   ├── sidepanel/          # Chrome Side Panel 页面
│   ├── options/            # 设置页面
│   ├── components/         # 共享组件
│   ├── services/           # API 服务
│   └── types/              # TypeScript 类型
├── docs/                   # 文档
├── dist/                   # 构建输出
└── README.md
```

### 开发命令

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 预览构建
```

本项目使用多个 Vite 配置文件分别构建不同部分：

## 隐私政策

我们高度重视用户隐私：

- ✅ 配置、最近保存记录和使用里程碑仅存储在您的浏览器本地
- ✅ 保存的内容直接传输到您的飞书表格，不经过第三方服务器
- ✅ AI 信息整理默认使用 Chrome 内置能力；自有 API Key 仅保存在用户本地
- ✅ 分享模板不包含凭证、资料库 ID 或已保存网页内容
- ✅ 问题反馈只在用户主动点击后打开，不自动附带当前网页内容
- ✅ 不收集任何个人身份信息
- ✅ 不向开发者服务器上传行为分析数据

详细隐私政策请查看 [PRIVACY.md](./PRIVACY.md)

## 常见问题

**Q: 保存失败，提示没有权限？**  
A: 请检查飞书是否允许这个应用编辑表格，以及 App ID 和 App Secret 是否复制完整。

**Q: 提示找不到某一列？**  
A: 飞书表格里的列名可能改过。请重新点击“读取表格列名”，再确认每一列应该保存什么。

**Q: 提取的内容不完整？**  
A: 有些网页内容是边加载边出现的，插件可能没抓全。可以刷新页面后再保存，或先只保存标题和链接。
